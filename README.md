# 🐾 PetLink — Red Social para Amantes de Mascotas

*PetLink* es una aplicación móvil desarrollada con fines sociales y tecnológicos.  
Permite a los usuarios *registrar, compartir y gestionar información sobre sus mascotas, además de **publicar anuncios de adopción, reportar animales perdidos y encontrar cuidadores o veterinarios cercanos.*

El proyecto implementa *módulos CRUD completos* y *subida de imágenes*, ideal para entornos de aprendizaje o portafolios de desarrollo móvil.

---

## 🚀 Características principales

- 👤 Registro y autenticación de usuarios  
- 🐶 Gestión de mascotas (nombre, especie, edad, fotos, vacunas)  
- 📸 Subida de imágenes (mascotas, adopciones, publicaciones)  
- 🧭 Reporte de mascotas perdidas con ubicación  
- 🏡 Publicaciones de adopción y comunidad  
- 💬 Comentarios y likes en publicaciones  
- 🔍 Búsqueda y filtros por tipo de animal, zona o estado

---

## 🧩 Módulos CRUD

| Módulo | Descripción | Funcionalidad |
|--------|--------------|----------------|
| 👤 *Usuarios* | Registro, login, edición de perfil | Crear, leer, actualizar, eliminar usuarios |
| 🐕 *Mascotas* | Información personal de cada mascota | CRUD de mascotas (nombre, edad, especie, fotos) |
| 📰 *Publicaciones* | Adopciones, reportes, noticias | CRUD con imágenes y descripción |
| 💬 *Comentarios* | Opiniones y respuestas | CRUD básico vinculado a publicaciones |
