# SkillBridge

**SkillBridge** es una aplicación móvil innovadora que conecta personas que desean **enseñar** y **aprender** entre sí mediante videollamadas cortas.  
El objetivo es fomentar el intercambio de conocimientos sin dinero, usando un sistema de créditos y reputación.

---

## Características
- Videollamadas cortas para enseñar o aprender nuevas habilidades  
- Chat integrado para materiales y comunicación  
- Sistema de créditos (enseña para ganar puntos y úsalos para aprender)  
- Buscador por temas, idioma o nivel  
- Calificaciones y perfiles personalizados  

---
## Objetivo

Eliminar las barreras económicas y geográficas del aprendizaje.
En SkillBridge, todos tienen algo que enseñar y algo que aprender.

## Estilo de Diseño

Interfaz minimalista y moderna

Paleta de colores suaves: celeste, blanco, lila y turquesa

Elementos redondeados, íconos intuitivos y tipografía amigable

Incluye un concepto de logotipo inspirado en un puente, símbolo de conexión y aprendizaje compartido

---
## Tipo de Aplicación

Educativa – Aprendizaje Social – Enseñanza Colaborativa entre Pares

---
## Visión y Propósito

Inspiradora • Global • Colaborativa • Moderna

SkillBridge empodera a todas las personas para ser maestros y aprendices, construyendo puentes entre culturas mediante el poder del conocimiento compartido.
